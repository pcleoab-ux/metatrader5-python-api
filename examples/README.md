# Exemplos

| Arquivo | Descrição |
|---------|-----------|
| `01_conexao.py` | Conectar ao terminal |
| `02_candles.py` | Baixar candles |
| `03_ordem.py` | Enviar ordem de compra |
| `04_posicoes.py` | Listar posições abertas |
| `05_indicadores.py` | SMA, EMA, RSI e MACD |
| `06_risco.py` | Cálculo de lote e risco |
| `07_bot_basico.py` | Bot simples com RSI |
| `08_fechar_posicoes.py` | Fechar todas as posições |

## Como usar

1. Abra o MetaTrader 5 e faça login na conta (preferencialmente demo)
2. Ative o Algo Trading
3. Execute o script desejado:

```bash
python 05_indicadores.py
```
